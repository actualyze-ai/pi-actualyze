# Security policy

## Reporting a vulnerability

Report vulnerabilities through GitHub's private vulnerability reporting:
open the [Security tab](https://github.com/actualyze-ai/pi-actualyze/security)
of this repository and choose **Report a vulnerability**. Do not open a
public issue, pull request, or discussion for a suspected vulnerability.

Include the affected version, how pi was configured, and the steps that
show the problem. Never include a real Actualyze API key; describe where a
key leaked instead of pasting it.

## Response targets

After we confirm a report, we aim to release a fix within these times,
counted from the report and set by severity:

| Severity | Fix target |
| -------- | ---------- |
| Critical | 3 days     |
| High     | 30 days    |
| Medium   | 60 days    |
| Low      | 90 days    |

## Supported versions

Fixes ship in a new release of the latest minor version. Older minor
versions do not receive fixes; upgrade to the latest release to get them.
